The entrance has the project name on its sign; the same entrance and residential
architecture appear in the project brochure. Five high-resolution frames were extracted from the project brochure (entrance,
landscaped street, residence elevations and clubhouse). The layout drawing was
also extracted, with a caption requiring confirmation of the latest schedule.
Frames are architectural renders,
not completed-site photographs. The website retains its existing plot prices and
labels rendered residences as design reference, rather than including a villa in
a plot price. Brochure images were sourced under the owner's current instruction;
no separate written developer permission is represented as having been received.

## Pearl

The listing cover is a layout plan, not a site photo. The brochure's suburban
house photo is not the Badwai site and is excluded from photography slots. The
existing supplied layout drawing remains in the separate plan section. No
reliable actual-site photograph was found in this search.

To remove blank visual slots, Pearl uses Bhopal city context with labels on the
hero, listing card, gallery thumbnails, and full-screen captions. These images
must not be relabelled as the project site, a view from the plots, or proof of
proximity. No distances or travel times were inferred.
